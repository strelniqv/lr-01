## Назначение

Программа читает длины массивов A и B с емкостью 20, элементы массива A вводятся пользователем. Далее идет ввод параметров a, x, h, по которым считаются элементы массива B. После чтения длин и параметров производятся модификации: удаление элементов, не удовлетворяющих условию fabs(B[i]) < 0.7 из второго массива (B), вставка 0 в позицию 0 в массиве A, замена всех отрицательных элементов массива А на 0.

## Ограничения

- Допустимый диапазон входных значений: длины массивов от 1 до 20; параметры a, x, h без ограничений
- Емкость массивов - 20
- Случаи, при которых программа сообщает об ошибке:
    * Значения длин массивов находятся вне диапазона от 1 до 20: ошибка ввода
    * Функция scanf прочитала меньше значений, чем требовалось (например, введена буква вместо числа): ошибка ввода

## Формат ввода и вывода

Ввод:

1. n - длина массива A, тип int
2. n элементов массива A, тип double
3. m - длина массив B, тип int
4. параметры a,x,h, необходимые для построения массива B, тип double

Вывод:
1. элементы массива A (элементы типа double с тремя знаками после запятой)
```text
A:
-3.000 0.500 1.700 7.000 
```

2. элементы массива B (элементы типа double с тремя знаками после запятой)
```text
B:
2.273 -2.397 2.477 -1.659
```

3. элементы массива B после удаления (элементы типа double с тремя знаками после запятой)
```text
B после удаления:
2.273 -2.397 2.477 -1.659 
```

4. элементы массива A после вставки (элементы типа double с тремя знаками после запятой)
```text
A после вставки:
0.000 -3.000 0.500 1.700 7.000
```

5. элементы массива A после изменения (элементы типа double с тремя знаками после запятой)
```text
A после изменения:
0.000 0.000 0.500 1.700 7.000
```

Сообщения:

- `ошибка ввода` — некорректный ввод длины массивов или несоответствие типов данных.
- `массив пуст` — если после удаления в массиве B не осталось ни одного элемента.
- `нет места для вставки` — если длина массива A равна его емкости (20).

Пример ввода:

```text
4
-5 0.7 2 -1
3
2 3 1
```

Вывод для этого примера:

```text
A:
-5.000 0.700 2.000 -1.000 
B:
-0.699 1.642 -1.360 
B после удаления:
1.642 -1.360 
A после вставки:
0.000 -5.000 0.700 2.000 -1.000 
A после изменения:
0.000 0.000 0.700 2.000 0.000 
```
